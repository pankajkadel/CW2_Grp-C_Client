# Staff Scheduling System – Staff Dashboard

This repository contains the client-side implementation of a Staff Scheduling System developed as part of the CW2 Group C project.

## Staff Dashboard

The Staff Dashboard allows employees to view and manage important information about their work schedules. It presents shift details, weekly earnings, working hours, requests, manager announcements and notifications in a modern and responsive interface.

The dashboard uses information from the existing login system to display the currently logged-in employee’s name and profile details.

## Features

* View the next scheduled shift
* View the weekly staff schedule
* Check weekly earnings
* Check completed and remaining shifts
* View total hours worked
* Submit a time-off request
* Request a shift swap
* Submit a request to drop a shift
* View payslip information
* Read manager announcements
* Check notifications and request updates
* View staff profile information
* Responsive design for desktop, tablet and mobile devices

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage
* Lucide Icons
* Google Fonts

## Project Files

### `staff_dashboard.html`

Contains the structure and content of the Staff Dashboard, including the sidebar, shift cards, weekly schedule, quick actions, notifications and request forms.

### `staff_dashboard.css`

Contains the complete visual design of the dashboard, including the dark-purple colour theme, responsive layout, cards, buttons, animations, forms and mobile styling.

### `staff_dashboard.js`

Contains the interactive functionality of the dashboard, including:

* Loading the logged-in employee’s information
* Opening and closing notifications
* Time-off request functionality
* Shift-swap functionality
* Drop-shift functionality
* Payslip functionality
* Navigation interactions
* Form validation
* Success notifications

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the HTML, CSS and JavaScript files are stored in the same folder.
4. Open `staff_dashboard.html` using the Live Server extension.
5. Test the dashboard buttons, notifications and request forms.

## Dashboard Design

The Staff Dashboard uses a modern dark-purple interface with responsive cards, clear typography, accessible navigation and colour-coded actions. The design is intended to help restaurant and hospitality employees easily understand and manage their work schedules.
